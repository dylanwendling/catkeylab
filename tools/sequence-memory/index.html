🧠 Sequence Memory Test

Follow the pattern of lights and sounds. How far can you get? Inspired by the classic Simon Says game, each round adds one more step to the sequence you need to remember.

Sequence Memory Test

Remember an increasingly long pattern of button presses with Simon Says interactive tones.

How to Use Sequence Memory Test

  1. Click "Start" to begin the test.
  2. Watch the sequence of pads that light up and listen to the tones.
  3. After the sequence finishes, click the pads in the same order.
  4. If correct, the sequence grows by one additional step.
  5. The test ends when you click the wrong pad in the sequence.

What This Test Measures

This test tracks your sequential short-term memory capacity: your ability to observe, store, and accurately reproduce an ordered pattern. Each additional step in the sequence increases the cognitive load on your working memory.

Why Use This Test

It's a great way to train your brain to remember patterns. It is also a well-known cognitive benchmark used in psychology.

How to Interpret Your Results

Reaching level 7–8 is average for most adults. Levels 10+ demonstrate strong sequential memory. The audio tones provide an additional memory cue: some people remember sequences better through sound than visual patterns alone.

Tips for Accurate Results

  • Pay attention to both the visual pattern and the audio tones: dual encoding helps memory.
  • Try to group the sequence into chunks of 3–4 rather than remembering each step individually.
  • Take the test in a quiet environment to avoid distraction.
  • Consistent practice can improve sequential memory over time.

Frequently Asked Questions

How does the Sequence Memory test work?

Watch the sequence of glowing pads, then repeat it in exact order. Each round adds one extra pad to the sequence.

What is a good score on the Sequence Memory test?

An average score is around level 7–8. Reaching level 12 or higher indicates excellent sequential memory recall.

Does practicing this test improve my memory?

Yes: sequential memory exercises like this can strengthen your working memory with consistent practice, similar to how musicians improve through repetitive pattern training.
