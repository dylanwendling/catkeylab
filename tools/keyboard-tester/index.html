交互式键盘按键测试

Interactive visual keyboard key tester. Press any key to see real-time highlight feedback, event keycode logging, and modifier status.

How to Use 交互式键盘按键测试

  1. Click inside the test area to make sure it has focus.
  2. Press any key on your physical keyboard.
  3. The corresponding key on the visual keyboard layout will highlight.
  4. Check the event log below for detailed key code and event information.
  5. Test all keys you want to verify: especially modifier keys (Shift, Ctrl, Alt).

What This Test Measures

This tool captures browser KeyboardEvent data for every keypress, including the key name, key code, and modifier key states. It visually maps each keypress to a standard keyboard layout so you can see exactly which keys are registering.

Why Use This Test

Use this tool to test a newly purchased keyboard, check a used keyboard before buying, troubleshoot keys that seem unresponsive or stuck, verify key rollover (pressing multiple keys simultaneously), or inspect the exact key codes being sent by your keyboard.

How to Interpret Your Results

Every key you press should immediately highlight on the visual layout and appear in the event log. If a key does not register at all, it may have a faulty switch or connection. If a key registers as a different key, there may be a layout or driver issue.

Tips for Accurate Results

  • Test multiple keys held simultaneously to check your keyboard's key rollover (NKRO) capability.
  • Try every modifier key combination (Shift, Ctrl, Alt, Win/Cmd) to verify they work together.
  • If testing a mechanical keyboard, press each key firmly to ensure the switch activates.
  • For laptop keyboards, test keys around the edges and corners where flex may affect contact.

Frequently Asked Questions

Does this keyboard tester support all keyboard layouts?

Yes! The tester listens to standard DOM KeyboardEvents so any QWERTY, AZERTY, or custom layout keys will register.

How do I test if a specific key is broken?

Press the key in question. If it does not highlight on the visual keyboard and does not appear in the event log, the key is not sending a signal to the browser. This usually indicates a faulty key switch, broken connection, or a driver issue.

Can I test a laptop keyboard with this tool?

Yes. Laptop keyboards send the same keyboard events as external keyboards. Open the tester in your browser and press keys directly on your laptop keyboard.

Can I test a mechanical keyboard?

Yes. Mechanical keyboards work the same way through browser keyboard events. You can also use this tool to verify key rollover: press multiple keys simultaneously to see how many register at once.

Why is key testing important for gaming and typing?

Key testing helps verify key rollover (NKRO), ghosting, and faulty key switches on mechanical or membrane keyboards.
