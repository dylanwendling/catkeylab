🔳 Visual Memory Test

Test your visual spatial memory by memorizing which squares on a grid are highlighted, then selecting them from memory. The grid grows larger and adds more highlighted squares each level.

🔳

Visual Memory Test

Remember an increasingly large board of squares as the grid expands.

How to Use Visual Memory Test

  1. Click "Start" to begin the test.
  2. A grid of squares will appear with some squares briefly highlighted.
  3. After the highlights disappear, click the squares that were highlighted.
  4. If you correctly identify enough squares, the grid expands for the next level.
  5. Three mistakes end the test.

What This Test Measures

This test tracks your visual-spatial short-term memory: the ability to remember the locations of items in a two-dimensional layout. As the grid expands from 3×3 to larger sizes, the test increasingly challenges your spatial encoding capacity.

Why Use This Test

Visual-spatial memory is important for navigation, design work, reading maps, and many everyday tasks that require remembering where things are located. This test provides a structured way to measure and exercise this ability.

How to Interpret Your Results

Reaching level 8–10 is average. Levels 12+ indicate strong visual-spatial memory. Performance depends on how effectively you can encode a spatial pattern during the brief display period.

Tips for Accurate Results

  • Look for shapes or patterns formed by the highlighted squares rather than memorizing each one individually.
  • Focus on the overall "shape" of the highlighted area as a single image.
  • Avoid looking away during the display phase.
  • Practice regularly to build your spatial pattern recognition.

Frequently Asked Questions

How does Visual Memory scale?

The board expands from 3x3 up to 7x7 grid with progressively more highlighted squares to remember.

What is the difference between Visual Memory and Chimp Test?

Visual Memory asks you to remember locations (which tiles were highlighted), while the Chimp Test asks you to remember both locations and their numerical order. They test related but distinct spatial memory skills.

Does screen size affect Visual Memory scores?

A larger screen can make the grid easier to see, but the core challenge is spatial pattern recall, which is more about memory capacity than visual acuity.
