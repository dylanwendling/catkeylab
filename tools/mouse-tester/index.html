Interactive online mouse button and scroll wheel tester. Test Left, Right, Middle, Side Back/Forward buttons and cursor tracking.

How to Use 鼠标按键与移动测试

  1. Click anywhere inside the mouse visualizer test area.
  2. The corresponding button (Left, Right, Middle, Side Back, Side Forward) will highlight when pressed.
  3. Test the scroll wheel by scrolling up and down inside the test area.
  4. Move your mouse to verify smooth cursor tracking.
  5. Check that all buttons register correctly and release properly.

What This Test Measures

This tool detects and displays which mouse buttons are being activated using standard browser mouse events. It shows button identity (MB1 through MB5), scroll wheel direction, and cursor position within the test area.

Why Use This Test

Use this tool to verify that all mouse buttons work correctly on a new mouse, troubleshoot an unresponsive button, check side buttons on a gaming mouse, or confirm scroll wheel functionality. It is especially useful when testing a used or refurbished mouse before purchase.

How to Interpret Your Results

Each mouse button should highlight immediately when pressed and release when you let go. If a button does not highlight at all, it may not be registering. If a button highlights without being pressed, the switch may have a hardware fault. Scroll wheel should register both up and down directions smoothly.

Tips for Accurate Results

  • Right-click inside the test area: the tool prevents the context menu so you can test MB2 freely.
  • If side buttons (MB4/MB5) do not register, your browser or operating system may be intercepting those buttons for navigation.
  • Test each button individually to isolate any issues.
  • Compare behavior across different browsers if a button seems unresponsive.

Frequently Asked Questions

Which mouse buttons can I test?

You can test Left Click (MB1), Right Click (MB2), Middle Click (MB3/Wheel), Side Button 4 (Back), Side Button 5 (Forward), and Scroll Wheel direction.

How to check if my mouse right click or side buttons work?

Click anywhere inside our interactive mouse visualizer. The corresponding mouse button will glow cyan in real time if functioning properly.

Can this tool detect mouse hardware damage?

This tool can confirm whether button presses are registering in the browser. If a button does not register at all, the switch may be faulty. However, the tool cannot diagnose internal hardware issues like degraded switches or sensor problems: only whether button events reach the browser.

Why won't my side buttons register?

Some browsers and operating systems intercept MB4 and MB5 for back/forward navigation. Try testing in a different browser, or check your mouse driver software for button remapping settings.
