CatKeyLab 🐾 - Free Online Keyboard, Mouse & Typing Tests

CatKeyLab is a free, high-performance web application built for testing mouse hardware, keyboard switches, WPM typing speed, click velocity, and reaction latency directly inside your web browser. Operating 100% client-side, it requires zero downloads, plugins, or accounts. All tests run locally to guarantee privacy and speed.

Our Tools & Tests

  • Reaction Time Test: Measure your visual reaction latency.
  • Sequence Memory Test: Simon-says interactive pattern recall.
  • Aim Trainer: Test your target acquisition speed and accuracy.
  • Number Memory Test: Digit span recall challenge.
  • Verbal Memory Test: Sequential word memory test.
  • Chimp Test: Working memory grid test.
  • Visual Memory Test: Spatial matrix pattern recall.
  • Typing Speed Test: WPM test with distraction-free interface.
  • Mouse Hardware Tester: Verify mouse buttons and scroll wheel.
  • Keyboard Key Tester: Verify key rollover and key codes.
  • Online Auto Clicker: In-browser automated clicking simulator.
  • CPS Speed Test: Measure your clicks per second.
  • Click Speed Test: Real-time velocity analytics.
  • Double Click Tester: Hardware chatter detector for faulty switches.

We provide a reliable platform for gamers, typists, and professionals to evaluate their hardware performance and cognitive benchmarks. Check out our About, Privacy Policy, and Terms of Service for more information on our anonymous global leaderboards and data practices.
