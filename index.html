CatKeyLab 🐾 - Free Online Keyboard, Mouse & Typing Tests

CatKeyLab is a free, high-performance web application built for testing mouse hardware, keyboard switches, WPM typing speed, click velocity, and reaction latency directly inside your web browser. Operating 100% client-side, it requires zero downloads, plugins, or accounts. All tests run locally to guarantee privacy and speed.

Which CatKeyLab Tool Should I Use?

  • Check whether keyboard keys work: Use the Keyboard Tester
  • Test mouse buttons and scroll wheel: Use the Mouse Tester
  • Check for accidental double clicks (mouse chatter): Use the Double Click Tester
  • Measure raw clicking speed (burst & endurance): Use the CPS Test
  • Analyze clicking speed consistency and velocity: Use the Click Speed Test
  • Measure typing speed (WPM) and accuracy: Use the Typing Speed Test
  • Measure visual reaction speed: Use the Reaction Time Test
  • Practice mouse aiming and target acquisition: Use the Aim Trainer
  • Test short-term pattern memory: Use the Sequence Memory Test
  • Test short-term digit span memory: Use the Number Memory Test
  • Test verbal word recognition memory: Use the Verbal Memory Test
  • Test spatial matrix pattern recall: Use the Visual Memory Test
  • Test rapid working memory (like chimpanzees): Use the Chimp Test
  • Automate mouse clicking inside the browser: Use the Auto Clicker

  • Play a physics 2D mini golf game: Use the Cat Mini Golf
